# Turnero · CC Consultorios

Agenda de turnos web para el consultorio de dermatología de la Dra. María Carolina Moreno (CC Consultorios, Rosario).

- **Computadora:** varios lunes a la vista; se toca un horario libre para dar el turno.
- **Celular:** la lista del día para tildar quién fue atendido.
- Pacientes que se recuerdan, sobreturnos, prácticas de 30 minutos, feriados y bloqueos, lista de espera, recordatorios por WhatsApp, planilla del día para imprimir y respaldo en Excel.

Los datos viven en Supabase y solo se pueden ver o modificar con la clave del consultorio.
Esta página es solo la aplicación: no contiene datos de pacientes.

Hecha con Preact + htm (sin compilación) y publicada con GitHub Pages.
